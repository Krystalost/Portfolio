## Renk Formatları ve Anahtar Kelimeler

<!-- named = Named Color (İsimlendirilmiş Renk)

hsla() = Hue Saturation Lightness Alpha (Saydam HSL)
Saydamlık ekli HSL üretir

Tamamen görünmez renk verir

currentColor = Current Color (Mevcut Renk)
Güncel yazı rengini alır -->
