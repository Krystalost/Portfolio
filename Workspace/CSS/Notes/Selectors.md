# Selectors

## Temel Seçiciler

<!-- * = Universal Selector (Evrensel Seçici)
Tüm elemanları seçer.

element = Type Selector (Etiket Seçici)
Belirtilen etiketleri seçer.

.class = Class Selector (Sınıf Seçici)
Belirtilen sınıfları seçer.

#id = ID Selector (Kimlik Seçici)
Belirtilen kimliği seçer.

, = Grouping Selector (Gruplama Seçicisi)
Birden fazla seçiciyi gruplar. -->

## Birleştirici Seçiciler

<!-- A B = Descendant Combinator (Alt Eleman Seçici)
İçerideki tüm elemanları seçer.

A > B = Child Combinator (Doğrudan Çocuk Seçici)
Doğrudan alt elemanı seçer.

A + B = Adjacent Sibling Combinator (Bitişik Kardeş Seçici)
Hemen sonraki kardeşi seçer.

A ~ B = General Sibling Combinator (Genel Kardeş Seçici)
Sonraki tüm kardeşleri seçer. -->

## Nitelik Seçicileri

<!-- [attr] = Attribute Selector (Nitelik Seçici)
Niteliğe sahip olanları seçer.

[attr="val"] = Exact Attribute Selector (Tam Değer Seçici)
Değeri tam eşleşeni seçer.

[attr^="val"] = Prefix Attribute Selector (Başlangıç Değer Seçici)
Belirtilen değerle başlayanı seçer.

[attr$="val"] = Suffix Attribute Selector (Bitiş Değer Seçici)
Belirtilen değerle biteni seçer.

[attr*="val"] = Substring Attribute Selector (İçeren Değer Seçici)
Değeri içeren elemanı seçer. -->

## Sözde Sınıflar

<!-- :root = Root Pseudo-Class (Kök Sözde Sınıfı)
Belgenin kök elemanını seçer.

:hover = Hover Pseudo-Class (Üzerine Gelme Sınıfı)
İmleç üzerindeki elemanı seçer.

:focus = Focus Pseudo-Class (Odaklanma Sınıfı)
Odaklanılan elemanı seçer.

:active = Active Pseudo-Class (Etkin Durum Sınıfı)
Tıklanan etkin elemanı seçer.

:visited = Visited Pseudo-Class (Ziyaret Edilmiş Sınıfı)
Ziyaret edilmiş bağlantıyı seçer.

:disabled = Disabled Pseudo-Class (Devre Dışı Sınıfı)
Pasif form elemanını seçer.

:checked = Checked Pseudo-Class (İşaretli Durum Sınıfı)
İşaretlenmiş seçim kutusunu seçer.

:required = Required Pseudo-Class (Zorunlu Alan Sınıfı)
Zorunlu form alanını seçer.

:first-child = First Child Pseudo-Class (İlk Çocuk Sınıfı)
İlk çocuk elemanı seçer.

:last-child = Last Child Pseudo-Class (Son Çocuk Sınıfı)
Son çocuk elemanı seçer.

:nth-child() = Nth Child Pseudo-Class (Sıralı Çocuk Sınıfı)
Belirtilen sıradaki çocuğu seçer.

:not() = Negation Pseudo-Class (Değilleme Sözde Sınıfı)
Koşula uymayan elemanı seçer. -->
