## Erişilebilirlik ve Etkileşim Nitelikleri

<!-- role = Role (Rol)

aria-label = Accessible Rich Internet Applications Label (Erişilebilirlik Etiketi)

aria-hidden = Accessible Rich Internet Applications Hidden (Erişilebilirlik Gizleme)
Ekran okuyucudan elemanı gizler.

tabindex = Tab Index (Sekme Sırası)
Klavye odaklanma sırasını belirler.

contenteditable = Content Editable (Düzenlenebilir İçerik)

spellcheck = Spell Check (Yazım Denetimi)
Yazım denetimi kontrolünü yönetir.

draggable = Draggable (Sürüklenebilir)
Elemanın sürüklenebilir olmasını sağlar.

translate = Translate (Çeviri)
Otomatik çeviri davranışını belirler.

inert = Inert (Etkisiz / Pasif)
