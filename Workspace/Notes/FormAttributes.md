# Form Attributes

## Doğrulama ve Sınırlandırma Nitelikleri

<!-- min = Minimum (En Az Değer)
Alt değer sınırı belirler.

max = Maximum (En Fazla Değer)
Üst değer sınırı belirler.

step = Step (Adım / Artış Aralığı)
Sayısal artış miktarını belirler.

minlength = Minimum Length (Minimum Uzunluk)
En az karakter sınırı.

maxlength = Maximum Length (Maksimum Uzunluk)

## Durum ve Seçim Kontrol Nitelikleri

<!-- readonly = Read Only (Salt Okunur)
Değiştirilemeyen veri alanı yapar.

checked = Checked (İşaretli)
Varsayılan olarak işaretli yapar.

selected = Selected (Seçilmiş)
Liste öğesini seçili yapar.

multiple = Multiple (Çoklu Seçim)
Çoklu veri seçimi sağlar.

accept = Accept (Kabul Etmek)
Yüklenecek dosya türünü kısıtlar. -->

## Kullanıcı Deneyimi ve Form Davranışı Nitelikleri

<!-- autocomplete = Auto Complete (Otomatik Tamamlama)

autofocus = Auto Focus (Otomatik Odaklanma)
Açılışta elemana otomatik odaklanır.

rows = Rows (Satırlar)

cols = Columns (Sütunlar)

enctype = Encoding Type (Kodlama Türü)
